1. التمريض والعيادة الطبية
Nursing & Clinic Module
جاهزية برمجية 90% 		نظام عيادة وصحة مهنية متكامل (113 KB كود):
  • سجل كشوفات يومية مع العلامات الحيوية (ضغط، سكر، حرارة، نبض).
  • سجل إصابات العمل وحوادث السلامة (OSH) مع رصد الأسباب الجذرية وشدة الحادث.
  • صيدلية العيادة وإدارة مخزون الأدوية وخصم الجرعات وتنبيهات النواقص.
  • تصاريح الراحة المرضية وأذونات خروج البوابة الأمنية (Gate Pass).
  • شاشة ذاتية للموظف لرفع المطالبات الطبية وفواتير التحاليل والعلاج.
 الربط الحكومي والجدولة السنوية:
  • الربط الخارجي: لا يوجد ربط API آلي مع التأمينات لإرسال استمارة (س 5)؛ يطبع التقرير يدوياً.
  • الفحص الدوري: يسجل ككشف عادي ولا يوجد جدول فحص سنوي إلزامي لعمال الخطوط الخطرة.

2. الحركة والنقل والأسطول
Fleet & Logistics Module
جاهزية برمجية 85% 		منظومة أسطول بـ 8 تبويبات تفاعلية بالكود:
  • سجل السائقين الداخليين وسجلات رخصهم وتقييم الأداء.
  • إدارة شركات النقل الخارجية (3PL) وأسعار النولون.
  • سجل شاحنات الأسطول وتواريخ الرخص والتأمين والفحص الفني.
  • سجل الرحلات اليومية وإثبات حركة البوابة وعدادات الكيلومتر (Odometer).
  • شاشة صرف وسداد مستحقات السائقين وتحويلها لـ Paid.
  • تسجيل حوادث ومخالفات السير وصيانة الشاحنات بالورش.
 ربط محطات الوقود وترحيل البدلات:
  • استهلاك الوقود: يسجل يدوياً مع كل رحلة ولا يوجد ربط API مباشر مع كروت محطات البنزين.
  • بدل الكيلومتر: يصرف كإذن نقدية مستقل ولا يرحل آلياً بضغطة زر داخل مسير الرواتب الموحد (37).

3. الدعم الفني وتكنولوجيا المعلومات
IT & Technical Support
جاهزية برمجية 80% 		مكتب خدمة وتذاكر مساعدة متكامل:
  • دورة حياة التذاكر: فتح تذكرة، تحديد نوع العطل (Hardware, Software, Network)، والأولوية.
  • عزل الصلاحيات: الموظف يرى تذاكره فقط، ومسؤول IT يرى الكل.
  • تحديث حالات التذكرة: Open ← In Progress ← Resolved مع مؤشرات الأداء.
  • سجل تدقيق أمني لحظي (Audit Log) يوثق كل دخول وتعديل بالنظام.
 جرد عتاد السيرفرات والنسخ الاحتياطي:
  • العتاد المكتبي: طابعات الباركود والسيرفرات تدار كأصول عامة في شاشة المعدات (24) وليس كجرد IT منفصل.
  • النسخ الاحتياطي: يدار عبر لوحة Supabase السحابية وليس عبر زر استعادة يدوي بداخل شاشات الـ ERP.

4. الشؤون القانونية
Legal Affairs & Compliance
جاهزية برمجية 60% 		إدارة القضايا والتحقيقات العمالية:
  • شاشة خاصة مقيدة بالمحامي والمالك (Lawyer / Owner Role).
  • جدول مخصص (legal_issues) لإدارة الشكاوى والتحقيقات.
  • تدفق إجرائي: فتح قضية ← تحقيق ← تصعيد للمالك ← إغلاق.
  • العقود التجارية مبرمجة في ملف مستقل (enterprise-contracts-forecast).
 الخصم الآلي للجزاء والتراخيص الصناعية:
  • الخصم المالي: قرار التحقيق لا يخصم فوراً من الراتب؛ بل يرسل لـ HR لتوقيعه في شاشة الجزاءات (46).
  • التراخيص والملكية: لا توجد شاشة خاصة للسجل الصناعي وبراءات الاختراع؛ بل تحفظ كمستندات مشفرة في DMS (60).

5. السلامة والصحة المهنية
Occupational Health & Safety (HSE)
جاهزية برمجية 65% 		إصابات العمل ومهمات الوقاية PPE:
  • سجل إصابات العمل والتحقيق في الأسباب الجذرية مدمج بـ clinic_injuries.
  • شاشة صرف الزي ومهمات الوقاية (Pages.uniforms): أحذية السلامة (Safety Shoes)، الأفرول، والمقاسات.
  • تدريبات السلامة والإخلاء تسجل بشاشة التدريب (49).
  • فحص أمان الماكينات يدار عبر أوامر الصيانة الوقائية (22).
 تصاريح العمل الخطرة وتفتيش الحريق:
  • تصاريح العمل (PTW): لا توجد شاشة منفصلة لتصاريح اللحام والأماكن المغلقة؛ بل تدار عبر شاشة المهام (59).
  • الدفاع المدني: فحص شبكات الإطفاء يدار كصيانة وقائية عامة وليس كقائمة فحص حريق مخصصة.

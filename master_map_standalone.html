NINJA SMART TECHNOLOGY FACTORY ERP

الخريطة الهندسية الكبرى للنظام بالكامل — ربط الإدارات الـ 15، الدورات التشغيلية، وسكيما الـ 170 جدول

1. إدارة المبيعات وخدمة العملاء
🔄 دورة المبيعات: RFQ ← عرض سعر ← أمر مبيعات ← BOM ← تحصيل خزنة ← إذن شحن ← فاتورة ← تسليم العميل
🔄 دورة المرتجعات: طلب مرتجع ← فحص جودة ← إذن إضافة ← إشعار دائن ← تسوية
🗄️ الجداول المرتبطة: sales_orders, quotations, customers, credit_notes, delivery_notes
2. إدارة المشتريات والموردين
🔄 دورة الشراء: طلب احتياج PR ← عروض أسعار RFQ ← أمر شراء PO ← استلام QC ← سداد المورد
🔄 دورة الموردين: تسجيل MVR ← تقييم أداء ← اعتماد المورد ← تجديد الاتفاقية
🗄️ الجداول المرتبطة: suppliers, purchase_orders, purchase_requests, supplier_invoices
3. إدارة الموارد البشرية والرواتب
🔄 20 دورة HR: توظيف ATS ← مقابلات ← عقود ← QR حضور ← سلف يومية/شهري ← جزاءات ← إجازات ← رواتب Pay
🔄 دورة التخارج: تسليم العهد ← تصفية مستحقات ← إخلاء طرف ← تجميد حساب
🗄️ الجداول المرتبطة: users, payroll, attendance, leave_requests, worker_advances, loans
4. إدارة الحضور والـ QR Code
🔄 مسح الكود اليومي ← مطابقة الشيفت ← تسجيل التأخير والغياب آلياً
🔄 تقديم تظلم تأخير ← موافقة HR ← تعديل كشف الحضور
🗄️ الجداول المرتبطة: attendance, shifts, attendance_appeals, QR_logs
5. إدارة التوظيف الذكي ATS
🔄 رفع السير الذاتية PDF ← تحليل المهارات آلياً بالذكاء الاصطناعي ← ترتيب المتقدمين
🔄 جدولة المقابلات الفنية ← تقييم اللجنة ← إصدار عرض العمل
🗄️ الجداول المرتبطة: ats_applications, job_postings, interview_schedules
6. الإدارة المالية والقيود المحاسبية
🔄 إنشاء قيد متوازن آلياً لكل حركة (بيع/شراء/رواتب) بدون تدخل يدوي
🔄 الإقفال الشهري ← ميزان المراجعة ← قائمة الدخل والميزانية العمومية
🗄️ الجداول المرتبطة: journal_entries, chart_of_accounts, fiscal_years, ledger
7. إدارة الخزائن والبنوك
🔄 صرف وقبض نقدي ← فحص السيولة المتاحة ← حظر السحب عند المكشوف
🔄 تحويل نقدية بين الخزائن والبنوك ← اعتماد الإدارة ← ترحيل الحسابات
🗄️ الجداول المرتبطة: finance_safes, bank_accounts, cash_transfers, bank_checks
8. إدارة مراكز التكلفة
🔄 توجيه المصروفات والرواتب لكود مركز التكلفة (خط إنتاج/مشروع)
🔄 تقرير تحليل الربحية والإنتاجية لكل مركز تكلفة على حدة
🗄️ الجداول المرتبطة: cost_centers, cost_allocations, line_profitability
9. إدارة المخازن ورصيد الخامات
🔄 إذن إضافة خامات ← خصم آلي فور التغذية لخط الإنتاج ← التنبيه لحد إعادة الطلب
🔄 الجرد الدوري الدوري ← تسوية عجز أو زيادة المخزون
🗄️ الجداول المرتبطة: inventory_items, stock_movements, warehouses, stock_adjustments
10. إدارة خطوط الإنتاج والـ BOM
🔄 أمر تشغيل ← خصم معايير الخامة من قائمة BOM آلياً ← متابعة نسب الإنجاز
🔄 إنهاء التصنيع ← تحويل المنتج التام لمخزن المبيعات
🗄️ الجداول المرتبطة: bom, production_orders, work_centers, finished_goods
11. إدارة ضبط الجودة والفحص المعملي
🔄 سحب عينات خامات المشتريات ← الفحص المعملي ← إجازة/رفض الشحنة
🔄 فحص عينات خطوط الإنتاج ← عزل العيوب قبل التعبئة والتحميل
🗄️ الجداول المرتبطة: qc_inspections, quality_standards, rejected_materials
12. إدارة الصيانة وقطع الغيار
🔄 تقديم بلاغ عطل طارئ ← صرف قطع الغيار من المخزن ← إصلاح الماكينة
🔄 الصيانة الوقائية السنوية ← تتبع ساعات التشغيل والزيوت
🗄️ الجداول المرتبطة: equipment, maintenance_logs, spare_parts, machine_downtime
13. إدارة أسطول الشاحنات والعداد
🔄 تتبع قراءة العداد Odometer ← صرف السولار ← حساب معدل استهلاك الوقود
🔄 التنبيه بمواعيد تراخيص الشاحنات والفحص الفني والإطارات
🗄️ الجداول المرتبطة: fleet_vehicles, fuel_logs, vehicle_licenses, odometer_reads
14. إدارة رحلات السائقين والشحن
🔄 تكليف السائق بالرحلة ← تسليم البضاعة للعميل ← استلام إشعار التسليم
🔄 تصفية عهد السائق ومصاريف الكارتة والوقود بالخزنة
🗄️ الجداول المرتبطة: fleet_trips, driver_allowances, trip_expenses, waybills
15. منظومة الذكاء الاصطناعي والـ CEO
🔄 شات بوت تفاعلي باللغة العربية للإجابة عن أسئلة واستفسارات الموظفين
🔄 لوحة قيادة تنبؤية للرئيس التنفيذي للتنبيه بالأخطار والمخاطر الماليّة
🗄️ الجداول المرتبطة: ai_prompts, ceo_analytics, ai_chat_history, system_kpis
